# Human vs Machine

Human vs Machine is a text-classification project that uses a Random Forest model to estimate whether a piece of text is human-written or AI-generated.

The project includes data preparation, feature engineering, feature-integrity checks, model training, evaluation, command-line prediction, and a Gradio dashboard for interactive testing.

## Project Overview

The model works from raw text and calculates seven linguistic features:

- Word count
- Character count
- Sentence count
- Average sentence length
- Flesch Reading Ease
- Gunning Fog Index
- Punctuation ratio

These features are then passed to a Random Forest classifier.

The project was revised after an earlier model produced 100% accuracy. That result was treated as suspicious because the model had access to all numerical columns in the dataset. The final version avoids using questionable supplied numerical features and instead recalculates the seven main features directly from `text_content`.

- `text_features.py` - contains the shared text-feature extraction functions.

## Datasets

The project uses two main datasets.

### Training Dataset

`ai_detection_dataset.csv`

- 1,367 records
- 684 Human samples
- 683 AI samples
- Main model-development dataset

### Testing Dataset

`human_vs_machine_testing_dataset_20.csv`

- 20 records
- 10 Human-style samples
- 10 AI-style samples
- Used as a small separate functional test set

Label meaning:

```text
0 = Human
1 = AI
```

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Train the Model

Place `ai_detection_dataset.csv` in the project folder and run:

```bash
python train.py
```

The training script creates:

```text
random_forest_ai_detector_regularized.pkl
training_metrics.json
feature_integrity_report.csv
```

For a faster code test:

```bash
python train.py --quick
```

Use the normal training command for the final project run.


- Recall

The train-test gap is also checked because a large gap can indicate overfitting.

## Feature Integrity

The project includes a feature-integrity audit.

The audit compares the numerical features supplied in the original CSV with the same features recalculated directly from `text_content`.

This check was added because some supplied values showed weak agreement with the actual text. The final model therefore uses features recalculated from the raw text instead of relying on the supplied values.

## Important Limitation

This project is an experimental text-classification system.

Its prediction should not be treated as absolute proof that a text was written by a human or generated by AI.

AI-text detection is difficult because writing style can overlap between human and machine-generated content. Better results require larger and more diverse datasets containing different human authors, topics, prompts, and AI systems.

- Testing text n-grams

## Project Purpose

The purpose of this project is to explore whether measurable writing characteristics can help distinguish human-written text from AI-generated text using a Random Forest classifier while maintaining a transparent and reproducible modelling process.
