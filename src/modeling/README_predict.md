# predict.py

This file makes predictions from the trained Human vs Machine model.

It is useful when you want a prediction without opening the Gradio dashboard.

## Required files

Keep these files in the same folder:

- `predict.py`
- `text_features.py`
- `random_forest_ai_detector_regularized.pkl`

Create the model file first by running `train.py`.

## Install packages

```bash
pip install pandas scikit-learn joblib
```

## Predict text directly

```bash
python predict.py --text "Paste the text you want to test here."
```

The output shows:

- Prediction
- AI probability
- Human probability
- Confidence

## Predict a text file

```bash
python predict.py --file sample.txt
```

## Show the extracted features

```bash
python predict.py --text "Your text here." --show-features
```

This also prints the seven linguistic features used by the model.

## Use a different model file

```bash
python predict.py --model path/to/model.pkl --text "Your text here."
```

## Important note

The result is a statistical estimate. It should not be treated as absolute proof that a text was written by a human or generated by AI.
